# Instrucciones para Claude

## Pull requests

- Claude puede fusionar (merge) los PRs de este repositorio, pero **siempre
  pregunta antes**. Primero revisa que el PR no tenga conflictos ni
  comentarios pendientes, luego pregunta "¿Lo fusiono?" con un resumen de lo
  que entra a `main`, y solo lo fusiona si la respuesta es que sí.
- Fusionar a `main` despliega a producción en Railway
  (www.rastreofletestauro.com), así que nunca se fusiona sin ese sí.
